## About:
<b>Memory Atlas</b> is your memory recall partner. The idea is to go deeper into a specific event from the past , aided by visual supplements to remember more of the past. Additionally, you can save the memory and visuals into a scrapbook which can be read later in the future.

The major goal to achieve here is to create a effective visual based journaling and memory recall system using text based and image based LLM.


→ This should be used in presence of caregivers or any other person who can assist people with dementia.

→ This can also be used to create storybooks of past memories by any people and can be saved for future reading.
<hr> 

## What are the Objectives:
* The users  should be able to type any memory prompts.
* The LLM should respond and communicate in friendly manner and try to dive deeper into the thoughts and kind of provide more elaboration each time.
* There should be a function to create a branch after each responses so that the user can dive deeper into each branch and delete those which doesn’t make much sense.

    <u>For instance;</u> Going to walk by Narayani River in the morning. If this is a prompt then the branches can be ‘With a dog’, ‘With friends’ or ‘any other detail you would like to extend on’. After going to one of the branches the user may not remember much so there should be a way to delete that branch and proceed to extend others. Sometimes there can be branches within a branch.

* The UI should be easy to use and not using colors or anything which can intimidate people.
* Also after chatting is done and the memory is sealed there should be a storybook created which details all the chats into a story format and also including the images created during the process.
* This is useful because the memories can be returned again and again and viewed again and again.
* For each search that you make online for something specific there should be a caregiver context which kind of includes the ability for caregivers or those assisting the person with the program to view more context so that they can proceed to ask more meaningful questions and engage memory effectively.
